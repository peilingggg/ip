# SE-EDU Java Coding Standard

Follow the rules in [references/java-coding-standard.md](references/java-coding-standard.md) for every Java change.

## Workflow

1. Read the reference before changing Java code.
2. Preserve existing behavior unless the task requires a behavior change.
3. Check every changed Java file against the reference.
4. Compile and run available tests after editing.
5. Use the Google Java Style Guide for topics the reference does not cover.
